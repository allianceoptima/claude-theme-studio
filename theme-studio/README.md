# Theme Studio

Recolor Claude Code's chat from 441 contrast-checked palettes in 63 collections,
or mix your own: prompts, replies, tool rows, the spinner, the footer, command
output and mod panes.

```
/plugin install theme-studio@claude-theme-studio
/theme                 open the studio
/theme dracula         apply by name
/theme random hockey   surprise me
/theme help            every command
```

Full documentation, the command reference and the option list are in the
[repository README](../README.md).
